Step 1  —  Define the problem
fitness_fn
DNA → float
objective to minimise
DNA (integer tuple)
TupleSpace(bounds)

Hamming-1 neighbors
or custom GraphSpace
or

Step 2  —  Choose an optimizer
DiscreteOptimizer

BasinHopping  ·  DifferentialEvolution  ·  MCMC  ·  SimulatedAnnealing
seed=  ·  cache_size=  ·  callbacks=
Step 3  —  Run
optimizer.run(n_iterations)
evaluate  →  cache  →  track best  →  step  →  callbacks
optional: progress=True  ·  record_history=True
Step 4  —  Result
Result  /  FRSTResult
best_solution  ·  best_value  ·  history
n_evaluations  ·  wall_time
FRST additionally: best_triangulation  ·  best_cy
