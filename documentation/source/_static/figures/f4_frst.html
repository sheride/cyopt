cyopt.frst — FRST optimisation layer
Input  —  CYTools polytope
reflexive Polytope
from the Kreuzer–Skarke database via cytools.fetch_polytopes()
or constructed from vertices: Polytope(verts)
Preparation  —  poly.prep_for_optimizers()
2-face triangulations
_cyopt_face_triangs
_cyopt_interesting: faces with $>1$ FRT
idempotent; cached on polytope
DNA bounds
_cyopt_bounds: ((0, $N_i{-}1$), …)
one coordinate per interesting face
directly usable as TupleSpace bounds
simplex sets
_cyopt_face_simp_sets
pre-indexed frozensets for O(1) reverse lookup
used by triang_to_dna
DNA encoding  —  monkey-patched Polytope methods
dna_to_frst(dna)
assemble face triangulations by DNA index
call triangfaces_to_frst()
returns None for non-solid cones
triang_to_dna(triang)
restrict to each interesting face
reverse-map simplex set → index
roundtrip: triang_to_dna(dna_to_frst(d)) = d
dna_to_cy(dna)
calls dna_to_frst then .get_cy()
also: cy_to_dna(cy)
Optimisation  —  two paths
FRSTOptimizer  /  frst_optimizer()
wraps any of the 8 generic optimizers
with TupleSpace(_cyopt_bounds)
fitness: DNA → Triang/CY → target → float
penalty for non-solid-cone DNAs
target(cy) → float or (float, ancillary)
FRSTFlipGraphSpace
lazy bistellar-flip neighbor generator
coarsening of Hamming-1: one flip per face
validity filter: dna_to_frst ≠ None
hub topology: asymmetric out-degree
plug in as space= to any optimizer
Output  —  decoded result
FRSTResult
best_dna  ·  best_value  ·  best_triangulation  ·  best_cy
history  ·  n_evaluations  ·  ancillary_data
