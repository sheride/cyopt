cyopt — Optimizer algorithms
Population-based  —  global search
GA
initialise population of size $P$
select → cross → mutate → elite carry-over
selection: tournament / roulette / ranked
crossover: $n$-point / uniform
target + fitness mode: inverse-square, Gaussian
DifferentialEvolution
wraps scipy.optimize.differential_evolution
integrality=True for all dimensions
strategies: best1bin, rand1bin, …
restarts population each run() call
RandomSample
uniform random baseline
draw from space.random(rng) each step
track the running best
useful as a performance reference
Graph-local  —  neighbor-based search
GreedyWalk
move to best improving neighbor
restart from random point when stuck
Hamming-1 or custom neighbor_fn
BestFirstSearch
backtrack: path + avoid set, oscillation detection
frontier: min-heap priority queue
never re-visits nodes (frontier mode)
BasinHopping
perturb → greedy descent → Metropolis accept
escapes shallow local minima
customisable perturb_fn & local_minimize_fn
Stochastic  —  temperature-driven acceptance
SimulatedAnnealing
propose via step_fn  ·  Metropolis accept
exponential cooling: $T(t) = T_\max \bigl(\tfrac{T_\min}{T_\max}\bigr)^{t/N}$
_step_count accumulates across run() calls
custom step_fn(dna, rng) → DNA
MCMC
propose via step_fn  ·  Metropolis-Hastings
accept with probability $\min\!\bigl(1,\, e^{-\Delta f / T}\bigr)$
fixed temperature $T$ (no cooling schedule)
custom step_fn(dna, rng) → DNA
Shared infrastructure (all optimizers)
EvaluationCache
LRU; avoids re-evaluating same DNA; serialised in checkpoints
Callbacks
CallbackInfo each iteration; return True for early stop; CheckpointCallback
Checkpoint / resume
save_checkpoint(path)  ·  load_checkpoint(path, fn); v1→v2 migration
